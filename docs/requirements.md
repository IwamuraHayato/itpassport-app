## 1. プロジェクト概要

### 1.1 目的・背景

ITパスポート試験の合格を目指す初学者（IT知識がほぼゼロの状態）が、気軽に学習を始められ、継続的に学習できる無料Webアプリケーションを提供する。

**解決する課題**:
- 既存の学習サービスは有料またはUI/UXが古い
- 初学者にとって学習の始めづらさ（会員登録の障壁）
- 学習進捗の可視化不足によるモチベーション低下
- モバイルでの学習体験が最適化されていない

### 1.2 ターゲットユーザー

**プライマリーユーザー**: ITパスポート試験の初学者
- IT知識がほぼゼロの状態からスタート
- スマートフォンでの学習を好む
- 短時間（10分程度）の隙間時間で学習したい
- 無料で気軽に始めたい

**ユーザー特性**:
- 年齢層: 18〜35歳
- 学習環境: 通勤・通学時間、休憩時間
- デバイス: スマートフォン（主）、PC（従）

### 1.3 提供価値

**競合優位性**:
1. **完全無料**: アカウント登録不要で即座に学習開始
2. **学習データの詳細分析**: 正答率・進捗の可視化によるモチベーション維持
3. **シンプルで使いやすいUI/UX**: モダンでスタイリッシュなデザイン
4. **モバイルファースト**: スマホ最適化による快適な学習体験
5. **効率的な復習**: 間違えた問題を重点的に学習できる

### 1.4 成功指標（KPI）

| 指標 | 目標値 | 測定方法 |
|-----|-------|---------|
| 月間アクティブユーザー | 100人 | LocalStorage UUID追跡 |
| 平均セッション時間 | 10分以上 | Google Analytics |
| 問題完了率 | 70%以上 | 開始セッション/完了セッション |
| 復習モード利用率 | 50%以上 | 復習セッション/総セッション |

## 2. 機能要件

### 2.1 MVP（Phase 0）- 最小viable product

**リリース目標**: 開発開始から4週間以内

#### 2.1.1 クイズ機能（必須）

**FR-001: 10問クイズセッション**
- **優先度**: P0（最優先）
- **説明**: ユーザーは10問単位でクイズに挑戦できる
- **詳細仕様**:
  - 問題はランダムに10問選出（重複なし）
  - 4択形式での回答
  - 1問ずつ表示（ページネーション不可）
  - 回答後、即座に正誤判定と解説を表示
  - 次の問題へ進むボタン
  - 進捗表示（例: 3/10問）

**FR-002: 回答・採点機能**
- **優先度**: P0
- **説明**: ユーザーの回答を判定し、正誤と解説を表示
- **詳細仕様**:
  - 選択肢をタップで回答
  - 正解: 緑色でハイライト + 正解メッセージ
  - 不正解: 赤色でハイライト + 正解を緑色で表示
  - 解説文を回答後に表示（折りたたみ可能）
  - 回答データをLocalStorageに保存

**FR-003: セッション結果表示**
- **優先度**: P0
- **説明**: 10問完了後に結果サマリーを表示
- **詳細仕様**:
  - 正答数/10問
  - 正答率（%）
  - 各問題の正誤一覧
  - 「もう一度挑戦」ボタン
  - 「復習する」ボタン（間違えた問題のみ）

#### 2.1.2 復習モード（必須）

**FR-004: 間違えた問題の復習**
- **優先度**: P0
- **説明**: 過去に間違えた問題だけを出題
- **詳細仕様**:
  - LocalStorageから間違えた問題IDを取得
  - 間違えた問題が10問未満の場合、全問出題
  - 10問以上ある場合、ランダムに10問選出
  - 通常のクイズセッションと同じフロー
  - 復習セッションであることを明示（ヘッダーに表示）

#### 2.1.3 学習履歴・統計表示（必須）

**FR-005: 学習統計ダッシュボード**
- **優先度**: P0
- **説明**: ユーザーの学習進捗を可視化
- **詳細仕様**:
  - 総学習問題数
  - 全体正答率（%）
  - 今日解いた問題数
  - 分野別正答率（ストラテジ・マネジメント・テクノロジ）
  - 正答率の推移グラフ（折れ線グラフ）
  - 最近のセッション履歴（直近5件）

**FR-006: 正答率・進捗グラフ**
- **優先度**: P0
- **説明**: 学習の成長を視覚的に表示
- **詳細仕様**:
  - 日別正答率の折れ線グラフ（7日間）
  - 分野別の円グラフ（正答率比較）
  - レスポンシブ対応（Chart.jsまたはRecharts使用）

#### 2.1.4 基本UI/UX（必須）

**FR-007: ホーム画面**
- **優先度**: P0
- **説明**: アプリのエントリーポイント
- **詳細仕様**:
  - 「クイズを始める」大きなCTAボタン
  - 学習統計サマリー（簡易版）
  - 「復習する」ボタン（間違えた問題がある場合のみ表示）
  - ナビゲーションメニュー（モバイル: ハンバーガーメニュー）

**FR-008: レスポンシブデザイン**
- **優先度**: P0
- **説明**: モバイルファーストのレスポンシブ対応
- **詳細仕様**:
  - モバイル（320px〜）: 優先最適化
  - タブレット（768px〜）: 2カラムレイアウト
  - デスクトップ（1024px〜）: 3カラムレイアウト
  - タッチ操作最適化（ボタンサイズ44px以上）

### 2.2 Phase 1（MVP後の優先機能）

**リリース目標**: MVP完成から2週間以内

**FR-009: 分野別クイズモード**
- **優先度**: P1

**FR-011: データエクスポート機能**
- **優先度**: P1

- **詳細仕様**:
  - JSON形式でのエクスポート

### 2.3 Phase 2（将来検討）

## 3. 非機能要件

### 3.1 パフォーマンス

**NFR-001: ページ読み込み速度**
- **要件**: 初回表示まで3秒以内（4G回線）
- **測定**: Lighthouse Performance Score 90以上
- **実装戦略**:
  - Next.js App Routerの静的生成活用
  - 画像最適化（next/image使用）
  - コード分割（dynamic import）

**NFR-002: レスポンス時間**
- **要件**: ユーザー操作に対して100ms以内で反応
- **測定**: Chrome DevTools Performance測定
- **実装戦略**:
  - LocalStorage操作の非同期処理
  - 楽観的UI更新（Optimistic UI）

**NFR-003: 同時アクセス対応**
- **要件**: 個人利用想定（同時アクセス〜10人）
- **スケーリング戦略**: Vercel無料プランで十分対応可能

### 3.2 セキュリティ

**NFR-004: データプライバシー**
- **要件**: 完全匿名利用（個人情報収集なし）
- **実装戦略**:
  - LocalStorageのみでデータ管理
  - アクセス解析は匿名UUID使用
  - Cookie不使用（GDPR対応不要）

**NFR-005: XSS対策**
- **要件**: ユーザー入力を安全に処理
- **実装戦略**:
  - React自動エスケープ活用
  - DOMPurifyでHTML解説文のサニタイズ

**NFR-006: HTTPS通信**
- **要件**: すべての通信をHTTPSで暗号化
- **実装戦略**: Vercelデプロイで自動対応

### 3.3 スケーラビリティ

**NFR-007: データ容量管理**
- **要件**: LocalStorage制限（5MB）内での運用
- **現状推定**:
  - 問題データ: 約500KB（100問 × 5KB/問）
  - 学習履歴: 約100KB（1000回答分）
  - 合計: 約600KB（十分余裕あり）

**NFR-008: 将来のクラウド同期準備**
- **要件**: LocalStorageからクラウドDBへの移行可能性
- **設計方針**:
  - データアクセス層の抽象化（Repository Pattern）
  - LocalStorage → Supabase移行パスの確保

### 3.4 可用性

**NFR-009: アップタイム**
- **要件**: 99%以上（月間ダウンタイム7時間以内）
- **実装戦略**: Vercel標準SLA（99.99%）に依存

**NFR-010: データバックアップ**
- **要件**: ユーザー自身によるデータエクスポート機能
- **実装戦略**: FR-011（Phase 1）で対応

### 3.5 ブラウザ互換性

**NFR-011: サポートブラウザ**
- **要件**:
  - iOS Safari 15+（モバイル優先）
  - Android Chrome 100+
  - Desktop Chrome/Edge/Firefox最新版
- **テスト戦略**: BrowserStack活用

**NFR-012: LocalStorage対応**
- **要件**: LocalStorage未対応ブラウザへの警告表示
- **実装戦略**: Feature Detection + Fallbackメッセージ

### 3.6 アクセシビリティ

**NFR-013: WCAG 2.1 AA準拠**
- **要件**: 基本的なアクセシビリティ対応
- **実装戦略**:
  - セマンティックHTML使用
  - ARIA属性適切に設定
  - キーボード操作対応
  - カラーコントラスト比4.5:1以上

## 4. データモデル設計

### 4.1 データ保存戦略

**アプローチ**: LocalStorage中心設計（MVP）
- **理由**:
  - 認証不要でも学習履歴を保持
  - サーバーコスト不要
  - オフライン動作可能
  - 個人情報収集なし（プライバシー保護）

**制約**:
- デバイス間でのデータ同期不可
- ブラウザキャッシュ削除でデータ消失リスク
- 5MB容量制限

**Phase 1以降の拡張**: オプショナルなクラウド同期
- Supabase無料枠活用
- 匿名UUID同期（メールアドレス不要）

### 4.2 LocalStorageスキーマ

#### 4.2.1 User Session（ユーザーセッション）

```typescript
interface UserSession {
  userId: string;              // UUID v4（初回訪問時生成）
  createdAt: string;           // ISO 8601形式
  lastAccessAt: string;        // 最終アクセス日時
  settings: {
    questionsPerSession: 10;   // 出題数（Phase 1）
    darkMode: boolean;         // ダークモード（Phase 1）
    fontSize: 'small' | 'medium' | 'large';  // Phase 1
    soundEnabled: boolean;     // 音声フィードバック（Phase 1）
  };
}
```

**LocalStorageキー**: `itpassport:user_session`

#### 4.2.2 Answer History（回答履歴）

```typescript
interface AnswerHistory {
  id: string;                  // UUID v4
  questionId: number;          // 問題ID（1〜100）
  userAnswer: number;          // ユーザーの回答（0〜3）
  correctAnswer: number;       // 正解（0〜3）
  isCorrect: boolean;          // 正誤判定
  answeredAt: string;          // 回答日時（ISO 8601）
  sessionId: string;           // セッションID（QuizSessionとリンク）
  category: 'strategy' | 'management' | 'technology';  // 分野
}
```

**LocalStorageキー**: `itpassport:answer_history`
**データ型**: `AnswerHistory[]`（配列）

#### 4.2.3 Quiz Session（クイズセッション）

```typescript
interface QuizSession {
  id: string;                  // UUID v4
  mode: 'normal' | 'review' | 'category';  // クイズモード
  category?: 'strategy' | 'management' | 'technology';  // 分野別モード時
  questionIds: number[];       // 出題された問題IDリスト（10個）
  startedAt: string;           // 開始日時
  completedAt?: string;        // 完了日時（未完了の場合null）
  score: number;               // 正答数（0〜10）
  totalQuestions: number;      // 総問題数（10）
}
```

**LocalStorageキー**: `itpassport:quiz_sessions`
**データ型**: `QuizSession[]`（配列）

#### 4.2.4 User Statistics（統計情報）

```typescript
interface UserStatistics {
  totalQuestionsAnswered: number;      // 総回答数
  totalCorrectAnswers: number;         // 総正解数
  overallAccuracy: number;             // 全体正答率（%）
  categoryStats: {
    strategy: {
      answered: number;
      correct: number;
      accuracy: number;
    };
    management: {
      answered: number;
      correct: number;
      accuracy: number;
    };
    technology: {
      answered: number;
      correct: number;
      accuracy: number;
    };
  };
  dailyStats: {
    date: string;                      // YYYY-MM-DD形式
    questionsAnswered: number;
    correctAnswers: number;
    accuracy: number;
  }[];  // 直近30日分を保持
  lastUpdatedAt: string;               // 最終更新日時
}
```

**LocalStorageキー**: `itpassport:user_statistics`

**更新タイミング**: 各回答後にリアルタイム更新

#### 4.2.5 Incorrect Questions（間違えた問題リスト）

```typescript
interface IncorrectQuestions {
  questionIds: number[];               // 間違えた問題IDのリスト
  lastUpdatedAt: string;
}
```

**LocalStorageキー**: `itpassport:incorrect_questions`

**更新ルール**:
- 不正解時: リストに追加（重複なし）
- 正解時: リストから削除（復習で正解した場合）

### 4.3 Question Data（問題データ）

**保存場所**: `data/questions.json`（静的ファイル）

```typescript
interface Question {
  id: number;                          // 1〜100
  category: 'strategy' | 'management' | 'technology';
  question: string;                    // 問題文
  choices: string[];                   // 選択肢（4つ）
  correctAnswer: number;               // 正解インデックス（0〜3）
  explanation: string;                 // 解説文（HTML可）
  source?: string;                     // 出典（例: "令和4年度秋期 問3"）
}
```

**データファイル例**:
```json
[
  {
    "id": 1,
    "category": "strategy",
    "question": "企業活動における...",
    "choices": [
      "選択肢A",
      "選択肢B",
      "選択肢C",
      "選択肢D"
    ],
    "correctAnswer": 1,
    "explanation": "<p>正解は<strong>選択肢B</strong>です。理由は...</p>",
    "source": "令和4年度秋期 問3"
  }
]
```

**ロード戦略**: ビルド時に静的インポート（Next.js最適化）

## 5. UI/UX設計方針

### 5.1 デザイン原則

**コンセプト**: モダンでスタイリッシュ、かつシンプルで学習に集中できるデザイン

#### 5.1.1 ビジュアルデザイン

**カラーパレット**:
- **プライマリ**: #3B82F6（青系 - 学習・信頼感）
- **セカンダリ**: #10B981（緑系 - 正解・成長）
- **エラー**: #EF4444（赤系 - 不正解）
- **ニュートラル**: #64748B（グレー - テキスト）
- **背景**: #F8FAFC（ライトグレー）

**タイポグラフィ**:
- **フォント**: システムフォントスタック（-apple-system, "Noto Sans JP"）
- **サイズスケール**:
  - 見出し: 24px〜32px（font-bold）
  - 本文: 16px（font-normal）
  - キャプション: 14px（font-light）
- **行間**: 1.6（読みやすさ重視）

**アイコン**: Heroicons v2（Tailwind公式推奨）

#### 5.1.2 レイアウト原則

**モバイルファースト**:
1. **Single Column Layout**（モバイル）
2. **Two Column Layout**（タブレット）
3. **Three Column Layout**（デスクトップ）

**スペーシング**: Tailwind CSS基準（4px刻み）
- 小: p-2（8px）
- 中: p-4（16px）
- 大: p-6（24px）

**コンポーネント設計**: Atomic Design準拠
- **Atoms**: Button, Input, Icon
- **Molecules**: QuestionCard, AnswerButton, StatCard
- **Organisms**: QuizSession, StatsDashboard
- **Templates**: QuizTemplate, StatsTemplate
- **Pages**: HomePage, QuizPage, StatsPage

### 5.2 主要画面設計

#### 5.2.1 ホーム画面（/）

**目的**: 学習の開始点とモチベーション維持

**レイアウト**（モバイル）:
```
┌─────────────────────┐
│ [ヘッダー]           │
├─────────────────────┤
│ 今日の学習           │
│ ■■■□□ 3/10問    │
├─────────────────────┤
│ [クイズを始める]     │  ← 大きなCTAボタン
├─────────────────────┤
│ 学習統計サマリー     │
│ 全体正答率: 75%     │
│ 今日: 3問           │
├─────────────────────┤
│ [復習する]          │  ← 間違えた問題がある場合のみ
├─────────────────────┤
│ 最近のセッション     │
│ • 10/11 10:00 80%  │
│ • 10/10 15:30 70%  │
└─────────────────────┘
```

**主要要素**:
- プログレスバー（今日の進捗）
- 大きな「クイズを始める」ボタン（44px以上の高さ）
- 統計サマリー（カード形式）
- 最近のセッション履歴

#### 5.2.2 クイズ画面（/quiz）

**目的**: 集中して問題に取り組める環境

**レイアウト**（モバイル）:
```
┌─────────────────────┐
│ [←] 問3/10         │  ← ヘッダー
├─────────────────────┤
│ 問題文が入ります     │
│ ...                 │
│                     │
```

## 7. リスクと課題

### 7.1 技術的リスク

**RISK-001: LocalStorageデータ消失**
- **影響度**: 高
- **発生確率**: 中（ユーザーのキャッシュクリア等）
- **対策**:
  - データエクスポート機能（FR-011、Phase 1）
  - ユーザーへの注意喚起（初回訪問時）
  - 将来的なクラウド同期準備（Repository Pattern）

**RISK-002: 問題データの著作権問題**
- **影響度**: 高
- **発生確率**: 低（ITAが公開している過去問使用）
- **対策**:
  - IPA公式の過去問を使用
  - 利用規約を確認・遵守
  - 独自問題作成も検討（Phase 2）

**RISK-003: モバイルブラウザ互換性**
- **影響度**: 中
- **発生確率**: 低（モダンブラウザ使用前提）
- **対策**:
  - iOS Safari 15+、Android Chrome 100+に絞る
  - Polyfillの適切な使用
  - 実機テスト徹底

### 7.2 プロダクトリスク

**RISK-004: ユーザー獲得難**
- **影響度**: 中
- **発生確率**: 中（競合多数）
- **対策**:
  - SEO最適化（キーワード: ITパスポート 無料 アプリ）
  - SNS活用（Twitter/note記事）
  - UI/UXでの差別化

**RISK-005: 学習効果の不明確さ**
- **影響度**: 中
- **発生確率**: 中（学習分析機能の重要性）
- **対策**:
  - 詳細な統計表示（FR-005, FR-006）
  - ユーザーフィードバック収集
  - 合格者の声を収集（Phase 2）

### 7.3 運用リスク

**RISK-006: 維持コスト増加**
- **影響度**: 低
- **発生確率**: 低（Vercel無料枠内）
- **対策**:
  - 静的生成中心（サーバーレス最小化）
  - 画像最適化徹底
  - アクセス数監視

**RISK-007: 問題データ更新の手間**
- **影響度**: 中
- **発生確率**: 中（年1回の試験改定）
- **対策**:
  - JSONファイルでの管理（手動更新容易）
  - 更新手順のドキュメント化
  - 将来的な管理画面検討（Phase 2）
